# OrcaSQL Workbench 文档与网站

本仓库用于维护 OrcaSQL Workbench 的公开用户文档与网站页面，并作为使用问题与文档反馈的统一入口。

## 内容与入口

- **用户文档（GitHub Wiki）**：入门指南、操作说明和常见问题。
- **公开网站（GitHub Pages）**：文档导航、隐私政策及相关声明。
- **问题反馈（GitHub Issues）**：Workbench 使用问题与文档反馈。

文档与页面正在准备中，发布后将补充访问链接。

## 问题反馈

如遇到 Workbench 使用问题，或发现文档内容有误、缺漏或过时，请通过 [Issues](https://github.com/ShawnXxy/orcasql-workbench-site/issues) 反馈。

请说明 Workbench 版本、问题现象和操作步骤。反馈中请勿包含账号凭据、客户数据或其他敏感信息。
